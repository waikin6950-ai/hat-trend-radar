运动/休闲大盘承压 · 帽子周边逆势

Lululemon：Q2 FY2026 预期收入 $2.450–2.475B，YoY -2 至 -3%（自上市以来第二次下滑）； Deckers (UGG/HOKA)：Q1 FY27 收入 $1.02B，YoY +5.7%首次破 10 亿，但毛利率被关税压； Nike FY26 Q4 收入 $10.97B（+0.72%）。帽子周边在运动大盘承压中反而逆势（Fitted Cap 现象）。

Trend · 05
2026-08

中国帽类出口实际关税 32.5%（HTS 6505 基础 + Section 301）

HTS 6505.00（棉质头饰）MFN 基础 7.5% + Section 301 China 25% = 32.5% （不含 Section 301 强迫劳动 12.5%，如包含则总税率更高）； Section 122 10% 基础关税 7/24 已失效；同日起 Section 301 强迫劳动 10/12.5% 替代 （覆盖 60 个贸易伙伴）。USTR 纺织品 TRQ（孟加拉 / 柬埔寨 / 印尼 / 马来西亚）原计划 9/1 落地，已推迟。

基于 Lyst +4,276% 数据 · 9 月可立即开模 / 报价的 3 类帽款

🥇 Priority · 01 · 紧追爆款

Fitted Cap（59FIFTY 廓形）

对标：New York Knicks 59FIFTY · Timberland × New Era × MLB
理由：Lyst Q2 +4,276% 搜索增长是 12 个月最大单一爆款；联盟 IP 授权模式成熟；TopOne 现有产能可直接接
成本预估：羊毛 / 棉斜纹 + 硬帽舌 + 6-Panel 结构，毛利 30-40%
起订量：500-1000 pcs / 配色
目标客户：美国独立品牌 + 欧洲运动 IP 授权商

⚠️ 联盟 IP 需谈授权（MLB / NBA / NFL 都有代理）
🥈 Priority · 02 · 大众市场

Trucker Cap（透气网背）

对标：经典 47Brand / Zephyr / Pioneer 等 Trucker 品牌
理由：Trucker 帽与 Baseball Cap 并列美国大众市场；透气网背适合夏季；价位亲民（$15-30）适合大批量
成本预估：泡沫前额 + 网眼后片，毛利 25-35%
起订量：2000-5000 pcs / 配色
目标客户：美国连锁零售 + 赛事周边 + 餐饮品牌联名

🥉 Priority · 03 · 街头通用

Snapback Cap（可调帽扣）

对标：Aimé Leon Dore 9FIFTY（Prep 美学）/ Palace × New Era（街头）
理由：Snapback 是 Fitted 与 Trucker 的中间型；一帽三吃（独立设计 / 街头 / 体育）；中国/越南/孟加拉产能充足
成本预估：塑料可调扣 + 平帽舌，毛利 30-40%
起订量：1000-3000 pcs / 配色
目标客户：全球独立品牌 + 街头品牌

🌍 重点开发市场（9 月）

🇺🇸 美国（Fitted Cap 主战场）

$5.4B 帽店市场（IBISWorld）+ 23,193 家门店 + NBA / MLB / NFL 联盟周边长期需求。 报价策略：DDP Los Angeles 或 FOB Shenzhen + 提供 5-7 配色组合； 起订量较高（1000-3000 pcs）。 重点客户类型：独立买手店 / 联盟 IP 授权商 / 体育周边分销。

🌏 亚太（最大体量）

亚太占全球 34.52%（最大），其中日本棒球帽文化深（NPB 联赛 + 甲子园）、 韩国 KBO 棒球 + K-pop 偶像带动。 报价策略：FOB China 即可 + 配额小批量灵活； 重点客户类型：日本体育用品店 / 韩国偶像周边 / 东南亚电商。
